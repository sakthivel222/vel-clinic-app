# Vel Clinic App

A full-stack physiotherapy clinic management system for Dr Kavitha at Vel Clinic.

## Tech Stack
- **Frontend**: React + Vite + Tailwind CSS (deployed on Vercel)
- **Backend**: Node.js + Express + Prisma ORM (deployed on Render)
- **Database**: PostgreSQL (Render)

## Features
- Patient management & timeline history
- Appointment scheduling & calendar
- Treatment/SOAP session notes
- Billing & invoices
- Exercise library
- Pain progress charts
- Task management
- PWA (offline support)

## Development

```bash
# Backend
cd backend && npm install && npm run start

# Frontend
cd frontend && npm install && npm run dev
```
